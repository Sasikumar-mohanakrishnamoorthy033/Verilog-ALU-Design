# 8-Bit Arithmetic Logic Unit (ALU) Design Using Verilog HDL

## Project Overview
Designed an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL and explored the digital implementation flow using Synopsys Fusion Compiler. The project demonstrates RTL design fundamentals and the implementation of combinational arithmetic and logic operations.

## Design Specifications
- **Data Width:** 8-bit
- **Opcode Width:** 3-bit
- **Design Type:** Combinational logic
- **Inputs:** A, B, and opcode
- **Outputs:** 8-bit result and zero flag
- **Operations:** Arithmetic and logical operations supported by the RTL

## Tools & Technologies
- Verilog HDL
- Synopsys Fusion Compiler
- Synopsys VCS (if used)
- Synopsys Verdi (if used)

## Design and Implementation Flow
1. RTL design using Verilog HDL
2. RTL compilation and functional verification
3. Synthesis and physical implementation using Synopsys Fusion Compiler
4. Timing analysis and implementation report review
